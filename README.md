# 📫 SimpleMail Landing Page

A sleek and responsive landing page for **SimpleMail**.

## 🔗 Live Demo

[try](https://simplemail-landing.vercel.app/)

## 🚀 Features

- Responsive design across devices
- Smooth navigation with React Router
- Stylish UI with Tailwind CSS
- Sections: Hero, Features, Pricing, Testimonials, Support

## 🛠 Tech Stack
- React
- Tailwind CSS
-	React Router DOM
-	CSS Animations


## 🧑‍💻 Getting Started

Clone the repository:
```
git clone https://github.com/your-username/simplemail-landing.git
cd simplemail-landing
```
Install dependencies: 
```
npm install
```
Run the app:  
```
npm run dev
```
